# Image credits

The Sentinel login screen shows two crowd-disaster case studies below the
fold. No other screen carries photography. Each card links to news
coverage of the event.

| File | Subject | Used for | Links to |
| - | - | - | - |
| `public/login/mina-hajj-2015.jpg` | Pilgrim crowds in the Mina valley during Hajj (the 2015 Mina stampede corridor) | Case-study reference on the login screen | https://www.nytimes.com/interactive/2015/09/24/world/middleeast/mecca-mina-stampede-hajj-maps.html |
| `public/login/kumbh-mela.avif` | Crowds at the Maha Kumbh Mela (the 2025 Prayagraj stampede) | Case-study reference on the login screen | https://www.business-standard.com/india-news/mahakumbh-stampede-india-deadliest-incidents-religious-festival-tragedy-125012900819_1.html |

Both images were supplied by the project team for this proof of concept.
They are shown as references to publicly reported events, each linked to
its source article. To change the set, replace the files and update this
table and the `CASE_STUDIES` list in `src/screens/S01Login.tsx`.
