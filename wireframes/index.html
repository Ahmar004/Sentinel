Every frame opens on its own by double-click. Nothing is fetched, no font or script comes from a network, and there is no build step, which is the same no-paid-service constraint the product itself is built under. Greybox throughout, except the four observation states and the four risk bands, which render in their real colour, pattern and label because those eight treatments are the requirement itself. Start at W00 Conventions: it is the contract every other frame inherits from.
