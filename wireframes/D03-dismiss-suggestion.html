Live Timeline Fleet History Replay
  1. The header names the exact suggestion being dismissed: rank, action and its alert. "Dismiss suggestion - rank 2", HOLD_AND_METER, A-1042 - a dismissal is still a decision about a specific option, not a generic "close". FR7.8
  2. The reason field is a plain textarea, labelled optional, and pre-empty by default. Nothing about the form implies a reason is required to proceed - the acceptance criterion only requires the actor, action, target and timestamp, so a reason is a courtesy to future review, not a gate on the action. FR7.8
  3. The dialog shows the exact audit entry before it is written, using the seven fields `srs.md` defines for `AuditEntry`: entryId, ts, actorId, action, targetType, targetId, previousValue and newValue. A coordinator dismissing an option can see precisely what will be recorded, not trust that something happens behind the button. FR7.8
  4. Why a dismissal is logged at all: an advisory system is only auditable if the decision not to act is recorded as deliberately as the decision to act. If dismissals left no trace, an examiner reviewing the audit log later would see confirmed suggestions but no record of the ones a coordinator judged unnecessary, which understates how much human judgement the system actually relies on. FR7.8
  5. Dismiss is type="submit" on a real <form onsubmit> calling event.preventDefault(); Cancel is type="button". Enter in the textarea or anywhere else in the form submits and dismisses with whatever reason is currently typed; Esc cancels and types nothing. Focus is trapped in the modal while open and returns to the card's Dismiss button on close. FR7.8
  6. Mobile carries the same seven-field audit preview, only set smaller, because what gets written to a 30-day record is exactly the kind of detail that must not be the first thing trimmed for a small screen. FR7.8
  7. The parent screen behind the scrim shows rank 1 already confirmed, which is why rank 2 is being dismissed here - the two dialogs in this file set tell one continuous story for A-1042: confirm the option that helps, dismiss the one that no longer applies. FR7.7 FR7.8
  8. Dismissed does not mean deleted. The suggestion keeps its identity (`SG-1044`) and moves to status DISMISSED rather than being removed from the record, matching how a superseded option reads EXPIRED rather than gone in `C05-suggestions` state 4. FR7.8
