  1. An alert event reuses the S04 layout exactly, read-only. Same header table, same full nine-feature attribution, same timeline shape - only the honest banner at the top changes, stating plainly that this is the frozen record from 19:42:10 yesterday and will never recompute. FR5.6 FR8.7
  2. Status reads CLEARED, not OPEN. A-1039 is history; it already resolved. The acknowledgement line names the actor without inventing a second timestamp beyond what the canonical record supports. FR8.1
  3. All nine signed contributions render, not a summary of three. The same zero-centred bars as the live view, because History does not get a lighter version of the truth. FR5.2
  4. A link forward to the suggestion this alert produced. An alert event and a suggestion event are two different records; naming SG-0771 here and anchoring to its outcome below is what lets a reviewer follow one incident end to end without leaving this screen.
  5. The map crop is explicitly marked illustrative, not stored. Only cell-level values are the historical record; nothing implies a stored image exists to be replayed pixel for pixel - that capability belongs to S10, not to a single event.
  6. The suggestion event shows the full option set, not only the one that was confirmed. Rank 2, superseded, and rank 3, rejected before issue, both render with their own reason, because an audit of "what was suggested" is incomplete if it only shows what happened to stick. FR7.4
  7. EXPIRED and REJECTED are labelled as distinct outcomes, not both dismissed. A person dismisses an option; a safeguard rejects one before it is ever offered; confirming one expires the others automatically. Three different actors, three different words, so the audit trail never blurs who or what made each option stop being live. FR7.8
  8. Every safeguard on the confirmed option still renders individually. Five named checks, each with its own PASS, even though nobody needs to check them again - the audit value is in showing exactly what was verified at the time. FR7.3

The outcome chart plots all three affected cells against all four band boundaries, 0.00, 0.40, 0.70 and 0.85, because a verdict of IMPROVED only means something next to where the risk bands actually sit. The lines stay continuous because these cells never lost observation during the window; a gap would show as a break, never a smoothed guess. FR8.6
