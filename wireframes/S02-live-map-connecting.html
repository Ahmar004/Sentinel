No site is configured yet

Riverside Arena has no plan, grid or zones on record, so there is nothing for the live map, zone strip or alert rail to draw.

An Administrator completes venue setup before this screen can show anything. s.iqbal is the Administrator on this deployment.

Coordinator cannot run venue setup - S11 is closed to this role.
  1. The banner names the state, not a spinner alone. "Connecting", the same word the connection chip uses, so a coordinator glancing at either one gets the same answer about whether the feed is live yet. design.md Section 10
  2. The top bar is skeleton, including the site name and the latency figure. A latency number has no meaning before a first measurement exists, so it is a placeholder bar, never "0.0s" and never the last session's value carried over. FR3.3
  3. Zone tiles carry skeleton bars where the risk score, the band chip and the coverage bar go - never 0.00 and never a 0% coverage bar. This is the entire point of the frame: a zone with no data yet must not be able to look identical to a zone that is genuinely calm. SRS 2.3 FR4.6
  4. The map draws nothing at all, not even gap. Gap is itself a claim - "no observation arrived for this cell" - and that claim cannot be made before the client has received a single batch to reason from, so the grid is entirely absent rather than pre-filled grey. FR6.3 SRS 2.3
  5. Same discipline at desktop scale, wider skeletons. Site name, grid dimensions and the connection chip are all placeholders together, because the desktop top bar has room to state more values and every one of them is equally unmeasured right now. FR3.3
  6. The banner spells out why nothing is drawn, not only that something is loading. A coordinator under time pressure should never have to guess whether a blank map means "safe" or "not yet connected". design.md Section 10
  7. Layers panel renders but every control is disabled. Toggling a layer before there is anything to toggle would imply a choice with no effect; disabling it states plainly that the panel is waiting on the same feed as the map. NFR5
  8. The alert rail skeleton mirrors a real card's shape without inventing its content. No count, no band chip, no score - only the layout a real card will eventually fill. FR5.1
  9. No site name in the top bar - "Sentinel" and a plain state label instead. Riverside Arena has not been named to the system yet, so the interface does not print a name it has not been given. FR9.1
  10. The empty state names who can fix this and by which screen, without offering the control itself. A Coordinator reading "an Administrator completes venue setup" and the specific Administrator's username knows exactly who to ask, while `S11` stays correctly closed to this role. FR9.1 FR10.3 design.md Section 10
  11. Nav rail is unaffected by the missing site. The role's five entries render exactly as they do when a site exists, because navigation is derived from the session, not from whether a venue has been configured - only the content area is empty. FR10.3
